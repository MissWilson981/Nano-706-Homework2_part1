This project explores the application of machine learning algorithms to classify wine samples based on their chemical properties. The dataset is obtained from the scikit-learn library and contains measurements of different chemical features, including alcohol content and malic acid concentration.

The dataset is divided into 70% training data and 30% testing data. The features are standardized, and the models are evaluated using classification accuracy. Accuracy represents the proportion of test samples correctly classified by each model.
This exercise demonstrates how machine learning algorithms can be applied to chemical datasets for classification. It provides practical experience in data visualization, preprocessing, model training, prediction, and evaluation.
